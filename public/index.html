新建配置组

默认链接指向本站托管的你提供的 default.conf。Mihomo 原订阅在 Shadowrocket 端只提取内联 proxies 节点；原规则和分组不会转换。不支持的协议节点会跳过；已支持协议若缺少必要参数仍会报错。

第一跳节点

填写自己节点的分享链接；# 后的文字是节点名，住宅节点经它链式连接。Hysteria2 链接可追加 &up=20&down=100（Mbps）写入 Mihomo 带宽。

住宅代理

第一跳会插入 Mihomo 原订阅每个分组的第 2 位，不改变各分组的默认选择。选「第一跳分组」时新建只含第一跳节点的 FIRST-HOP 分组并把兜底指向它（没有原订阅分组时也会新建）；Shadowrocket 同样。不填原订阅时不能沿用原 MATCH，默认直连。

UDP 443：第一跳支持 UDP（http:// 不支持），且所有住宅节点都是支持 UDP 的 SOCKS5 时，OpenAI / Claude 的 QUIC 直接经住宅 IP 发出；否则自动对这些域名拒绝 UDP 443，让 App 立即改走 TCP。

生成结果

iPhone · Shadowrocket 操作步骤

  1. 在首页把「节点订阅」地址作为 Subscribe 导入。
  2. 在「配置」中添加远程 .conf 地址，启用它，并把全局路由设为「配置」。
  3. 逐个打开住宅节点右侧的 ⓘ，在「代理通过」选择第一跳节点 first-hop，保存。不要给 first-hop 自己设置代理通过。
  4. 在「设置 → 订阅」开启「保持代理通过」；更新后核查链式关系。

UDP 443 拒绝仅针对所列 OpenAI / Claude 域名；实际命中仍取决于客户端能否识别该 UDP 连接的域名。新节点的导入及链式关系请在 iPhone 上验证。

用 Shadowrocket 等客户端扫码导入；二维码包含订阅令牌，请勿外泄。
